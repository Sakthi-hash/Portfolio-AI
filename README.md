# ECE & Embedded Systems AI Portfolio ⚡

A premium, interactive AI-powered web portfolio showcasing ECE credentials, academic projects, hands-on internships, and student leadership milestones. Powered by **Google Gemini 2.5** and built using **Python & Streamlit**.

## Features 🚀
- **Hulk AI Assistant:** An on-page, custom-trained AI assistant representing the candidate to recruiters. Hulk AI can answer questions about skills, C programming, microcontroller debugging, and internship projects.
- **Hands-On Internships:** Detailed records of 4 ECE industry internships (Coimbatore Airport, Vasantha Advanced Systems, Brigade LED) with expandable on-site photos and verification proofs.
- **Featured Projects Grid:** 5 ECE and ML projects (Autonomous Fault Isolation grid, Solar-Powered Precision Irrigation capstone, ML Crop Yield Predictor, Ultrasonic Radar, and Li-Fi Audio transmitter) in a clean columns grid.
- **Academic Presentations Tabbed View:** Showcases presentations, PPT seminars (M-ary PAM, optical fiber, SDN), and research comparisons, divided between Undergraduate and Diploma achievements.
- **Student Leadership Spotlight:** Highlight of the 3-day post-pandemic Long Industrial Visit coordination with crisis-management and on-site group photos.

## Tech Stack 🛠️
- **Frontend/Backend:** Python & Streamlit
- **AI Brain:** Google Gemini 2.5 API (`google-generativeai`)
- **Styling:** Custom CSS (Glassmorphic dark design)
- **Deployment:** Streamlit Community Cloud

## Local Setup 💻
1. Clone this repository:
   ```bash
   git clone https://github.com/Sakthi-hash/Portfolio-AI.git
   cd Portfolio-AI
   ```
2. Set up virtual environment and install packages:
   ```bash
   python -m venv venv
   .\venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```
