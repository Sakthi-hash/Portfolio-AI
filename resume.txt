   - Phase 2: Literature Survey - Researched Smart Grid standards, IoT distribution, LoRa capabilities, existing patents, and paper limitations to identify system novelty.
   - Phase 3: System Architecture - Designed a pole-to-transformer hierarchical network with pole nodes, transformer nodes, ring topology, alternative backup supplies, and sectional control.
   - Phase 4: Hardware Selection - Selected ESP32 (later improved to Arduino UNO for pole nodes), LoRa SX1278 for transceiver communications, and INA219 Current/Voltage sensors (finetuned over PZEM).    - Phase 5: Communication Design - Designed LoRa messaging formats, master-slave packet acknowledgments, retry mechanisms, and handshakes.
   - Phase 6: Theft Detection Algorithm - Developed a comparison engine: Transformer Power vs. Sum of Pole Node Power. Utilized cable resistance and current measurements to calculate technical line loss and flag abnormalities via an adaptive line loss threshold.
   - Phase 7: Fault Detection Algorithm - Programmed offline house sequence analysis to detect open circuits, line faults, and pole failures. Consecutive offline poles indicate line faults, whereas random offline poles indicate possible theft.
   - Phase 8: Fault Isolation - Built autonomous sectional tripping logic. Trips only the affected section, keeping the rest of the electrical grid energized.
   - Phase 9: Self Healing - Designed automatic restoration logic using alternate feeder pathways in a ring topology.
   - Phase 10: Resilience Features - Implemented 'Store and Forward' (Micro SD logging during LoRa loss), 'Last Gasp' (battery alert sent right before system power down), and 'Safe Mode' buzzer alarms.
   - Phase 11: Dashboard Development - Built a Python dashboard with live monitoring, event logging, historical analytics, and SQLite database storage.
   - Phase 12: Analytics - Integrated risk modeling, theft probability engines, and heat map rendering modules.
   - Phase 13 & 14: Documentation & Presentation - Completed full SRS documentation, patent comparisons, flowcharts, block diagrams, and technical PPTs.
   - Phase 15: Future Scope - Incorporating AI theft forecasting, GIS mapping, edge AI, and smart solid-state breakers.
